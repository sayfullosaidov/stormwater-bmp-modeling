## Sherrerd Field BMP Hydrologic Model

This project develops a simplified hydrologic model of the Sherrerd Field stormwater BMP using observed rainfall and outlet-flow data.

The model represents the main processes controlling the BMP response:

**Rainfall → turf/root-zone storage → gravel storage → native-soil infiltration + underdrain flow → outlet structure → measured outflow**

The goal is to understand how rainfall is stored, infiltrated, and discharged through the system, and to evaluate whether a simplified process-based model can reproduce observed storm behavior.

Observed storm events are used to calibrate and validate uncertain model parameters. Once the model is reasonably constrained by field data, it can be used to investigate how BMP performance changes under different storm magnitudes and antecedent moisture conditions.

The model intentionally uses a lumped representation of the subsurface drainage system rather than explicitly modeling every individual perforated pipe.
